테이블 상세 정의

1. users 사용자 프로필

Supabase Auth와 연동된 사용자 프로필 정보를 저장합니다. 인증은 Supabase Auth에서 처리하고, 추가 프로필 정보만 이 테이블에 저장됩니다.

컬럼명 데이터 타입 제약조건 설명
idPK UUID REFERENCES auth.users(id) Supabase Auth 사용자 ID
name TEXT NOT NULL 사용자 이름
emailUNIQUE TEXT NOT NULL, UNIQUE 이메일 주소
current_cohort_idFK UUID REFERENCES cohorts(id) 현재 참여 중인 기수 ID
is_admin BOOLEAN DEFAULT false 관리자 여부
created_at TIMESTAMPTZ DEFAULT NOW() 생성 일시
updated_at TIMESTAMPTZ DEFAULT NOW() 수정 일시
인덱스
  • idx_users_email ON users(email)
  • idx_users_current_cohort ON users(current_cohort_id)
  • idx_users_is_admin ON users(is_admin) WHERE is_admin = true
RLS 정책
  • Users can view own data - SELECT: auth.uid() = id
  • Users can update own data - UPDATE: auth.uid() = id
2. cohorts 기수 정보

챌린지 기수(코호트) 정보를 관리합니다. 각 기수는 시작일, 종료일, 정원, 상태 등의 정보를 가집니다.

컬럼명 데이터 타입 제약조건 설명
idPK UUID DEFAULT gen_random_uuid() 기수 고유 ID
name TEXT NOT NULL 기수명 (예: "2024년 1기")
start_date DATE NOT NULL 시작일
end_date DATE NOT NULL 종료일
description TEXT nullable 기수 설명
status cohort_status DEFAULT 'recruiting' 기수 상태
record_type record_type_enum DEFAULT 'both' 기록 유형 설정
max_participants INTEGER nullable 최대 참여 인원
created_at TIMESTAMPTZ DEFAULT NOW() 생성 일시
updated_at TIMESTAMPTZ DEFAULT NOW() 수정 일시
인덱스
  • idx_cohorts_status ON cohorts(status)
  • idx_cohorts_start_date ON cohorts(start_date)
RLS 정책
  • Anyone can view cohorts - SELECT: true (authenticated)
  • Only admins can modify cohorts - ALL: is_admin = true
3. user_cohorts 사용자-기수 참여

사용자와 기수 간의 다대다(N:M) 관계를 저장하는 중간 테이블입니다. 사용자의 기수 참여 이력을 추적합니다.

컬럼명 데이터 타입 제약조건 설명
idPK UUID DEFAULT gen_random_uuid() 레코드 고유 ID
user_idFK UUID NOT NULL, REFERENCES users(id) 사용자 ID
cohort_idFK UUID NOT NULL, REFERENCES cohorts(id) 기수 ID
joined_at TIMESTAMPTZ DEFAULT NOW() 참여 일시
completed_at TIMESTAMPTZ nullable 완료 일시
status participation_status DEFAULT 'active' 참여 상태
제약조건
  • UNIQUE(user_id, cohort_id) - 사용자당 기수별 1개 참여만 허용
인덱스
  • idx_user_cohorts_user ON user_cohorts(user_id)
  • idx_user_cohorts_cohort ON user_cohorts(cohort_id)
  • idx_user_cohorts_status ON user_cohorts(status)
4. challenges 챌린지 진행

사용자별, 기수별 30일 챌린지 진행 상태를 저장합니다. 완료된 날짜는 배열로 관리됩니다.

컬럼명 데이터 타입 제약조건 설명
idPK UUID DEFAULT gen_random_uuid() 레코드 고유 ID
user_idFK UUID NOT NULL, REFERENCES users(id) 사용자 ID
cohort_idFK UUID NOT NULL, REFERENCES cohorts(id) 기수 ID
completed_days INTEGER[] DEFAULT '{}' 완료된 날짜 배열 (1-30)
status challenge_status DEFAULT 'waiting' 챌린지 상태
applied_at TIMESTAMPTZ DEFAULT NOW() 신청 일시
approved_at TIMESTAMPTZ nullable 승인 일시
started_at TIMESTAMPTZ nullable 시작 일시 (사전설문 완료 시)
completed_at TIMESTAMPTZ nullable 완료 일시
제약조건
  • UNIQUE(user_id, cohort_id) - 사용자당 기수별 1개 챌린지만 허용
인덱스
  • idx_challenges_user ON challenges(user_id)
  • idx_challenges_cohort ON challenges(cohort_id)
  • idx_challenges_status ON challenges(status)
5. daily_records 일일 기록

일일 자기돌봄 및 타인친절 행동 기록을 저장합니다. 행동 데이터는 JSONB 형식으로 유연하게 저장됩니다.

컬럼명 데이터 타입 제약조건 설명
idPK UUID DEFAULT gen_random_uuid() 레코드 고유 ID
user_idFK UUID NOT NULL, REFERENCES users(id) 사용자 ID
cohort_idFK UUID NOT NULL, REFERENCES cohorts(id) 기수 ID
day INTEGER NOT NULL, CHECK (1 ≤ day ≤ 30) 챌린지 일차 (1-30)
self_care_actions JSONB DEFAULT '[]' 자기돌봄 행동 배열
kindness_actions JSONB DEFAULT '[]' 타인친절 행동 배열
quote TEXT nullable 오늘의 명언
is_completed BOOLEAN DEFAULT false 기록 완료 여부
created_at TIMESTAMPTZ DEFAULT NOW() 생성 일시
updated_at TIMESTAMPTZ DEFAULT NOW() 수정 일시
JSONB 구조 (self_care_actions, kindness_actions)
  • [{ "id": "uuid", "label": "운동하기", "isCustom": false, "memo": "30분 조깅" }, ...]
제약조건
  • UNIQUE(user_id, cohort_id, day) - 사용자/기수/일차별 1개 기록만 허용
6. surveys 사전/사후 설문

챌린지 시작 전(사전)과 완료 후(사후) 설문 응답을 저장합니다. 34문항의 응답과 계산된 점수가 JSONB로 저장됩니다.

컬럼명 데이터 타입 제약조건 설명
idPK UUID DEFAULT gen_random_uuid() 레코드 고유 ID
user_idFK UUID NOT NULL, REFERENCES users(id) 사용자 ID
cohort_idFK UUID NOT NULL, REFERENCES cohorts(id) 기수 ID
survey_type survey_type NOT NULL 설문 유형 (pre/post)
responses JSONB NOT NULL 설문 응답 데이터
scores JSONB nullable 계산된 척도별 점수
created_at TIMESTAMPTZ DEFAULT NOW() 제출 일시
설문 척도 (4개, 총 34문항)
  • 번영척도 (Flourishing Scale) - 8문항: 목적의식, 관계, 참여, 기여, 역량, 자존감, 낙관성, 존중
  • 삶의 만족도 척도 (SWLS) - 5문항: 이상, 조건, 만족, 목표달성, 선호
  • 자기자비척도 (SCS-SF) - 12문항: 자기친절, 공통인간성, 마음챙김 (역채점 포함)
  • 친절행동척도 - 9문항: 도움, 기부, 안내, 양보, 문잡기, 헌혈, 도움, 자원봉사
제약조건
  • UNIQUE(user_id, cohort_id, survey_type) - 사용자/기수별 사전/사후 각 1회만 허용
7. community_posts 커뮤니티 게시글

코호트 기반 커뮤니티 게시글을 저장합니다. 익명 닉네임과 아바타가 자동 생성됩니다.

컬럼명 데이터 타입 제약조건 설명
idPK UUID DEFAULT gen_random_uuid() 게시글 고유 ID
user_idFK UUID NOT NULL, REFERENCES users(id) 작성자 ID
cohort_idFK UUID NOT NULL, REFERENCES cohorts(id) 기수 ID
room_id TEXT NOT NULL 게시판 구분 ID
content TEXT NOT NULL 게시글 내용
recommended_quote TEXT nullable AI 추천 명언
likes INTEGER DEFAULT 0 좋아요 수
anonymous_name TEXT NOT NULL 익명 닉네임
avatar TEXT NOT NULL 이모지 아바타
created_at TIMESTAMPTZ DEFAULT NOW() 작성 일시
인덱스
  • idx_community_posts_cohort ON community_posts(cohort_id)
  • idx_community_posts_room ON community_posts(room_id)
  • idx_community_posts_created ON community_posts(created_at DESC)
RLS 정책
  • Users can view posts in their cohort - SELECT: 같은 기수 게시글만 조회
  • Users can insert own posts - INSERT: 본인 게시글만 작성
  • Users can update/delete own posts - UPDATE/DELETE: 본인 게시글만 수정/삭제
  • Admins can view all community_posts - SELECT: 관리자 전체 조회
8. community_comments 댓글

커뮤니티 게시글에 대한 댓글을 저장합니다. AI 추천 명언은 시스템 댓글로 표시됩니다.

컬럼명 데이터 타입 제약조건 설명
idPK UUID DEFAULT gen_random_uuid() 댓글 고유 ID
post_idFK UUID NOT NULL, REFERENCES community_posts(id) 게시글 ID
user_idFK UUID NOT NULL, REFERENCES users(id) 작성자 ID
content TEXT NOT NULL 댓글 내용
likes INTEGER DEFAULT 0 좋아요 수
is_system_quote BOOLEAN DEFAULT false AI 추천 명언 여부
anonymous_name TEXT NOT NULL 익명 닉네임
created_at TIMESTAMPTZ DEFAULT NOW() 작성 일시
인덱스
  • idx_community_comments_post ON community_comments(post_id)
  • idx_community_comments_created ON community_comments(created_at)
9. applications 신청서

챌린지 참가 신청서를 저장합니다. 관리자가 승인하면 6자리 코드가 발급됩니다.

컬럼명 데이터 타입 제약조건 설명
idPK UUID DEFAULT gen_random_uuid() 신청서 고유 ID
name TEXT NOT NULL 신청자 이름
email TEXT NOT NULL 이메일 주소
motivation TEXT NOT NULL 참여 동기
status application_status DEFAULT 'pending' 신청 상태
code TEXT nullable 승인 코드 (6자리)
code_used_at TIMESTAMPTZ nullable 코드 사용 일시
cohort_idFK UUID REFERENCES cohorts(id) 배정된 기수 ID
applied_at TIMESTAMPTZ DEFAULT NOW() 신청 일시
processed_at TIMESTAMPTZ nullable 처리 일시
인덱스
  • idx_applications_email ON applications(email)
  • idx_applications_status ON applications(status)
  • idx_applications_code ON applications(code)
RLS 정책
  • Anyone can insert applications - INSERT: 누구나 신청 가능
  • Only admins can view applications - SELECT: 관리자만 전체 조회
  • Anyone can verify approved code - SELECT: 승인된 코드 검증은 누구나
  • Only admins can update applications - UPDATE: 관리자만 상태 변경

RPC 함수 (Stored Procedures)

increment_post_likes FUNCTION

게시글 좋아요 수를 원자적으로 증가시킵니다.

파라미터 타입 설명
post_id UUID 좋아요를 증가시킬 게시글 ID
  • RETURNS VOID | SECURITY DEFINER
increment_comment_likes FUNCTION

댓글 좋아요 수를 원자적으로 증가시킵니다.

파라미터 타입 설명
comment_id UUID 좋아요를 증가시킬 댓글 ID
  • RETURNS VOID | SECURITY DEFINER

트리거 (Triggers)

update_updated_at TRIGGER FUNCTION

레코드 수정 시 updated_at 컬럼을 현재 시간으로 자동 업데이트합니다.

적용 테이블
  • users - update_users_updated_at
  • cohorts - update_cohorts_updated_at
  • daily_records - update_daily_records_updated_at
